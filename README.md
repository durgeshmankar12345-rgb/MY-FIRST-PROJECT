# 🚀 Durgesh Technology Company

A modern and responsive **technology company portfolio website** created using HTML and CSS. This project showcases web development services, skills, portfolio projects, team members, and contact information.

## 🌐 Project Overview

**Durgesh Technology Company (DTC)** is a frontend web development project designed to present a professional technology company/ developer portfolio.

The website includes:

- 🏠 Home / Hero Section
- 👨‍💻 About Us
- 💻 Services
- 🛠️ Skills
- 🖼️ Portfolio
- 👥 Team
- 📩 Contact Section
- 📱 Responsive Design
- ✨ Modern UI with animations and icons

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts – Poppins
- Font Awesome
- Responsive Web Design
